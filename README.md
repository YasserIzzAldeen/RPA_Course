# Robotic Process Automation (RPA) Learning Journey  

This repository documents my learning journey and hands-on practice in **Robotic Process Automation (RPA)**.  
The course I completed covered multiple stages, from programming fundamentals to automation design and development using UiPath.  

---

## 📚 Course Stages & Topics Covered  

### 1. Programming Fundamentals  
- **C# Fundamentals**  
  - Basic syntax, data types, control structures  
  - Object-oriented programming basics  
- **Python Fundamentals**  
  - Variables, loops, functions  
  - Working with libraries  

### 2. Automation Business Analysis  
- Understanding business processes  
- Creating **Process Definition Documents (PDDs)**  
- Identifying automation opportunities  

### 3. Solution Design  
- Translating PDDs into technical design  
- Creating **Solution Design Documents (SDDs)**  
- Mapping business needs to automation workflows  

### 4. Automation Development with UiPath  
- Using **UiPath Studio** to design and build workflows  
- Implementing **best practices** with the **REFramework (Robotic Enterprise Framework)**  
- Managing and deploying automations with **UiPath Orchestrator**  
- Error handling, logging, and project organization
